# MapXplorer 3D — Real Places Fixed

## Run locally
1. Open the `MapXplorer-3D` folder in VS Code.
2. Open `index.html` with Live Server.
3. Wait for the map to load.
4. Test the search bar with: `Brookefields`, `Ganga Hospital`, `VOC Park`, or `PSG`.
5. Click **SEARCH** or press Enter.

## Real-place search
- The app first tries OpenStreetMap Nominatim and Photon.
- If an online provider is blocked or unavailable, the app automatically uses its built-in Coimbatore real-place fallback, so the feature still works during local testing.
- No API key is required.

## Important
Do not open a different old copy of the project. In VS Code, open this exact folder and run this exact `index.html`.
