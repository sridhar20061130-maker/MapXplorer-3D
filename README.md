# MapXplorer 3D — AI Reactive Companion V10

V10 adds an AI Command Center with browser-local command parsing, optional browser speech recognition, speech synthesis, character emotion synchronization, quick actions, activity logging, and a lightweight performance mode.

## Commands
Try commands such as:
- locate me / GPS
- scan nearby places
- start route / navigate
- journey mode / travel
- arrival / celebrate
- calm mode

## Voice
Speech output uses the browser's built-in Speech Synthesis API. Voice input uses SpeechRecognition/Web Speech API when supported by the browser. No cloud AI API key is required for this local feature.

## Performance
The V10 panel uses CSS-only effects and a bounded activity log. It does not add Three.js or another heavy runtime dependency.
